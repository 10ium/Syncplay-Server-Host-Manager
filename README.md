# 🎬 Syncplay Server Manager | کنترل پنل سرور سینک‌پلی

A lightweight, modern, and open-source desktop control panel for managing private **Syncplay** servers on Windows. Built with Python & Tkinter with zero heavy web dependencies, native Persian (RTL) support, process-isolated bandwidth monitoring, and one-click Telegram sharing.

یک کنترل پنل سبک، مدرن و متن‌باز برای مدیریت سرورهای اختصاصی **Syncplay** روی ویندوز. ساخته شده با پایتون، بدون وابستگی‌های سنگین مرورگر، با پشتیبانی کامل از راست‌به‌چپ (RTL)، آمار دقیق ترافیک و قالب هوشمند کپی در تلگرام.

---

## ✨ امکانات و قابلیت‌ها (Features)

- **⚡ فوق‌العاده سبک و کم‌مصرف (Ultra-Lightweight):** مصرف حافظه کمتر از ۳۰ مگابایت رم بدون استفاده از مرورگرهای سنگین یا الکترون.
- **▶️ روشن و خاموش کردن تک‌کلیکی (One-Click Start/Stop):** راه‌اندازی و توقف کامل پردازه سرور سینک‌پلی با یک کلیک.
- **📊 آمار کاملاً ایزوله و اختصاصی (Process-Isolated Metrics):** محاسبه و نمایش لحظه‌ای سرعت تبادل و حجم ترافیک فقط برای خود سرور سینک‌پلی (بدون محاسبه ترافیک پس‌زمینه ویندوز).
- **👥 نمایش زنده دوستان آنلاین (Connected Clients Breakdown):** تشخیص لحظه‌ای تعداد افراد حاضر در اتاق به تفکیک شما و دوستان.
- **🔔 اعلان صوتی هوشمند (Audio Chime Alerts):** پخش صدای اعلان ویندوز هنگام ورود یا خروج دوستان به اتاق.
- **📱 قالب هوشمند اشتراک‌گذاری در تلگرام (Telegram One-Tap Copy):** دکمه کپی اختصاصی با فرمت کدهای مارک‌داون تلگرام (بدون اضافه شدن https://) که به دوستان اجازه می‌دهد با یک ضربه هر مشخصه را کپی کنند.
- **🛡️ بررسی و ثبت خودکار فایروال (Automated Windows Firewall):** بررسی واقعی باز بودن پورت در فایروال ویندوز به همراه دکمه ثبت خودکار با دسترسی مدیر.
- **🌐 استعلام خودکار و ویرایش دستی آی‌پی‌ها:** استعلام خودکار آی‌پی اینترنت و آی‌پی داخلی سیستم با امکان تغییر و ذخیره دستی.
- **📖 راهنمای داخلی تشخیص CGNAT و تنظیم انواع مودم‌ها:** آموزش گام‌به‌گام بررسی نات اپراتورها و فوروارد پورت در مودم‌های یوتل، تی‌پی‌لینک، دی‌لینک، هواوی و ...

## 🚀 پیش‌نیازها و نحوه اجرا (Requirements & Usage)

### پیش‌نیازها:
1. پایتون ۳.۸ یا بالاتر (نصب شده روی ویندوز).
2. برنامه رسمی **Syncplay** (نصب شده در مسیر استاندارد یا کنار برنامه).
3. کتابخانه پایتون `psutil`:
```bash
pip install psutil
```

### نحوه اجرا:
کافیست فایل `Run_Manager.bat` یا `server_manager.py` را اجرا کنید:
```bash
python server_manager.py
```

## ⚙️ ساختار فایل‌های پروژه (File Structure)

- `server_manager.py`: برنامه اصلی کنترل پنل.
- `config.example.json`: فایل نمونه تنظیمات برای عموم.
- `config.json`: فایل تنظیمات شخصی کاربر (در گیتهاب ایگنور شده است تا آی‌پی و رمز فاش نشود).
- `add_firewall.bat`: اسکریپت باز کردن پورت در فایروال ویندوز.
- `remove_firewall.bat`: اسکریپت حذف قانون فایروال.
- `.gitignore`: جلوگیری از ارسال فایل‌های حساس به مخزن.

## 🌐 راهنمای فوروارد پورت و تشخیص CGNAT

برای اینکه دوستانتان از طریق اینترنت به سرور متصل شوند:
1. پورت پیش‌فرض سرور (`24680 TCP`) را در مودم خود روی آی‌پی داخلی سیستم (Local IP) فوروارد (Virtual Server) کنید.
2. مطمئن شوید اینترنت شما پشت CGNAT (رنج 100.64.0.0/10) نیست.
3. در برنامه از دکمه **«📖 راهنمای مودم و تست CGNAT»** برای مشاهده جزئیات کامل استفاده کنید.
